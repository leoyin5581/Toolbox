
# FUD 化成數據彙整工具

> 所有運算都在本機瀏覽器完成，不使用任何外部函式庫或網路。

## 專案簡介

這是一個專門處理電池化成（Formation）數據的瀏覽器工具。只需將 `.fud` 資料夾拖入頁面，即可自動解析、彙整各充放電階段的數據，並提供圖表視覺化、統計分析與報告輸出功能。

**零依賴、零安裝、零上傳**——所有資料處理都在你的瀏覽器中完成，不會經過任何伺服器。

## 功能特色

### 資料載入

- 支援拖曳多個資料夾直接載入（可一次選取多個工單資料夾）
- 支援「加入資料夾」按鈕重複載入
- 自動偵測 `.fud` 檔案並解析 CSV 內容
- 支援 UTF-8 與 Big5 編碼
- 暫存檔功能：儲存/載入 `.fudsess` 檔案，下次開啟即可還原所有資料與設定

### 數據彙整

- 每個 `.fud` 檔案生成一列，欄位依充放電階段（Action）排列
- 可勾選要顯示/輸出的階段與欄位
- 階段命名自訂：可將 Action 名稱改為自訂顯示名稱
- 計算欄位：支援以公式欄位引用其他欄位（例：`[D0]/([C0-CC1]+[C0-CV])*100`），支援 `+ - × ÷` 與括號

### 理論容量與克容量回推

- 依有效面積、CA CW、Active ratio、克容量、並數計算理論容量
- 回推各階段實際克容量（mAh/g）
- 預設值可套用全部工單，亦支援個別覆寫

### 圖表視覺化

- **散佈圖**：各階段一圖，顯示電芯序號 × 數值
- **箱型圖**：依工單分組的箱型圖
- **自訂 X-Y 散佈圖**：自由選擇 X、Y 欄位，附帶相關係數
- **原始曲線**：時間–數值曲線圖，支援多電芯並列與第二 Y 軸
- 圖表雙擊可下載 PNG
- 每張圖可設定 Y 軸範圍
- **一鍵輸出 PPT**：將所有圖表匯出為 PowerPoint 簡報（純 JS 產生 `.pptx`，不需任何函式庫）

### 統計分析

- 支援多選統計項目：顆數、平均、標準差、最小值、中位數、最大值
- 可選擇要統計的階段/欄位
- 一鍵複製統計表至剪貼簿（可直接貼入 Excel）

### 匯出功能

- **CSV 下載**：匯出彙整表格為 CSV 檔案（含 BOM，Excel 可正確開啟）
- **複製到剪貼簿**：以 Tab 分隔複製，可直接貼入 Excel
- **PPT 簡報**：一鍵將圖表匯出為 PowerPoint 檔案

## 使用方式

1. 用瀏覽器開啟 `fud-formation-tool.html`
2. 將包含 `.fud` 檔案的資料夾拖曳至頁面中（或點擊「加入資料夾」按鈕）
3. 工具會自動解析檔案並顯示彙整結果
4. 勾選要顯示的階段與欄位，調整設定後查看結果
5. 使用圖表區進行視覺化分析
6. 匯出需要的報表

### 檔案格式說明

`.fud` 檔案為 CSV 格式，工具會自動尋找包含 `End Status` 欄位的表頭列，並過濾 End Status 為 0 或空白的列，只保留有效的化成數據。

每個資料夾視為一個工單（Group），資料夾名稱即為工單號碼。

## 技術規格

| 項目 | 說明 |
|------|------|
| 檔案格式 | 單一 `.html` 檔案 |
| 外部依賴 | 無（Zero Dependency） |
| 瀏覽器支援 | 現代瀏覽器（Chrome / Edge / Firefox / Safari） |
| 編碼支援 | UTF-8、Big5 |
| 圖表引擎 | 原生 Canvas API |
| PPT 產生 | 純 JS 實作 ZIP/PPTX 格式 |
| 暫存功能 | localStorage + `.fudsess` 檔案（支援 gzip 壓縮） |

## 檔案結構

```
fud-formation-tool.html   # 單一 HTML 檔案，包含所有 CSS 與 JavaScript
```

## 開發備註

- 此工具完全在客戶端執行，不發送任何資料至伺服器
- 圖表繪製使用原生 Canvas API，不依賴 Chart.js 等第三方函式庫
- PPT 匯出功能使用純 JavaScript 實作 ZIP 壓縮與 OOXML 格式產生
- 暫存檔支援 gzip 壓縮（瀏覽器支援 `CompressionStream` 時自動啟用）
